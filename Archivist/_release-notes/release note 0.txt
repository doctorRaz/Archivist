Очередной релиз Archivist для импорта и синхронизации Markdown-файлов, экспортированных из ChatGPT с помощью **[chatgpt-exporter](https://github.com/pionxzh/chatgpt-exporter)**.

* Исправлена обработка повторно экспортированных разговоров.
* Добавлено корректное определение существующего разговора по `conversation_id`.
* Добавлена проверка `update_time` при синхронизации:

  * более новая версия разговора заменяет существующий файл;
  * одинаковая версия пропускается;
  * более старая версия не перезаписывает существующий файл.
* Сохранена совместимость со старыми файлами, в которых отсутствует `update_time`.
* Исправлено создание дубликатов при повторной обработке экспортов.
* Улучшена работа индексов и использование `aliases`/`title`.
* Добавлено сохранение времени изменения Markdown-файла в соответствии с `update_time` разговора.
* Добавлены и расширены автоматические тесты.
* Настроена проверка сборки и тестов через GitHub Actions.

Релиз предназначен для использования с Markdown-экспортами ChatGPT.

При повторной обработке одного и того же разговора Archivist теперь учитывает не только идентичность разговора, но и время его последнего обновления, что предотвращает перезапись более свежей версии более старым экспортом.
