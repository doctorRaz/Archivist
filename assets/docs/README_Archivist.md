# Archivist

Утилита для обработки Markdown-файлов, экспортированных с помощью **[chatgpt-exporter](https://github.com/pionxzh/chatgpt-exporter)**.

Archivist импортирует разговоры из ZIP-архивов экспорта ChatGPT, организует их в каталоге назначения, синхронизирует существующие файлы и поддерживает обслуживание уже созданного vault.

## Возможности

- Обработка последнего ZIP-архива или всех архивов экспорта ChatGPT.
- Распаковка архивов во временный каталог.
- Поиск и обработка экспортированных Markdown-файлов.
- Чтение и запись YAML front matter.
- Определение даты создания и изменения разговора.
- Организация файлов по каталогам `YYYY/MM-MMMM`.
- Нормализация имён файлов.
- Синхронизация с уже существующими Markdown-файлами.
- Сравнение метаданных и обновление файла, если экспортированная версия новее.
- Идентификация разговора по `conversation_id` с использованием `chat_link` как fallback.
- Защита от создания дубликатов.
- Сохранение времени изменения файла (`LastWriteTime`).
- Построение и обновление навигационных индексов.
- Режим обслуживания существующего vault без обработки ZIP-архивов.

## Установка

Скачай последний релиз **[Archivist](https://github.com/doctorRaz/Archivist/releases/latest)**.

Archivist не требует установки: распакуй архив и запусти `Archivist.exe`.

Для запуска требуется **.NET 6 Runtime**.

## Использование

Основной синтаксис:

```text
Archivist -s <каталог> -d <каталог> [опции]
```

### Параметры

- `-s`, `--source <каталог>` — каталог с ZIP-архивами экспорта ChatGPT.
- `-d`, `--destination <каталог>` — каталог назначения. Если отсутствует, будет создан.
- `-p`, `--pattern <маска>` — маска ZIP-файлов. По умолчанию `*.zip`.
- `-m`, `--maintenance <каталог>` — обслуживание существующего vault без обработки архивов.

### Опции

- `-a`, `--all` — обработать все ZIP-архивы. По умолчанию обрабатывается только последний найденный архив.
- `-h`, `--help`, `/?` — показать справку.

Примеры:

```text
Archivist -s "D:\GPT\Archives" -d "D:\GPT\Vault"
Archivist -s "D:\GPT\Archives" -d "D:\GPT\Vault" -a
Archivist --source "D:\GPT\Archives" --destination "D:\GPT\Vault" --all
Archivist --maintenance "D:\GPT\Vault"
```

Параметры `--source` и `--destination` используются для обычного импорта. Режим `--maintenance` является отдельным режимом работы и принимает каталог существующего vault.

## Синхронизация

Archivist не просто копирует экспортированные файлы. Перед записью он проверяет существующий файл и сравнивает метаданные.

Это позволяет повторно запускать импорт без бесконтрольного создания копий одного и того же разговора. При наличии более новой экспортированной версии существующий Markdown-файл обновляется.

Исходные ZIP-архивы не изменяются.

## Структура каталога

Каталог назначения формируется по времени создания разговора в UTC:

```text
Output/
├── 2026/
│   ├── 08-August/
│   ├── 09-September/
│   └── ...
└── ...
```

## Метаданные

Поддерживаются, в частности, следующие поля YAML front matter:

- `title` — название разговора;
- `aliases` — альтернативные имена;
- `tags` — теги;
- `create_time` — время создания;
- `update_time` — время последнего изменения;
- `date_export` — дата экспорта;
- `chat_link` — ссылка на разговор ChatGPT;
- `conversation_id` — идентификатор разговора.

`conversation_id` имеет приоритет над идентификатором, извлечённым из `chat_link`. Если явного идентификатора нет, Archivist использует `chat_link` как fallback.

## Нормализация имён файлов

Нормализация применяется к имени Markdown-файла:

- `#` заменяется пробелом;
- последовательности пробельных символов заменяются одним пробелом;
- ведущие и завершающие пробелы удаляются;
- `_` сохраняется без изменений;
- Unicode-символы, включая кириллицу, сохраняются.

## Индексы и обслуживание

В обычном режиме Archivist поддерживает навигационные индексы при синхронизации.

Для уже существующего vault доступен режим обслуживания:

```text
Archivist --maintenance "D:\GPT\Vault"
```

В этом режиме ZIP-архивы не обрабатываются. Archivist проходит по существующему vault, нормализует имена файлов и обновляет/перестраивает `_index.md`.

## BAT-скрипты

В каталоге `run` находятся готовые BAT-скрипты для локального запуска Archivist:

- `Archivist.bat` — обработка последнего подходящего экспорта;
- `Archivist all.bat` — обработка всех подходящих экспортов;
- `Archivist_work.bat` — тот же запуск с другим исходным каталогом;
- `Archivist all_work.bat` — обработка всех экспортов из другого исходного каталога.

Скрипты используют маску `*-export-markdown*`, параметр `-a` для обработки всех архивов и заданные в них локальные пути к исходному каталогу, vault и `Archivist.exe`. Перед использованием на другой машине пути необходимо проверить и при необходимости изменить.

## Ограничения

Archivist не изменяет содержимое сообщений разговора. Он работает с Markdown-файлами экспорта, их YAML front matter, именами файлов и структурой каталогов.

При ошибках обработки приложение завершает работу с ненулевым кодом возврата.
